# MemeTraderPro v3 Theses

This folder contains first-class MemeTraderPro research theses.

Rules:

- One thesis per Markdown file.
- Thesis status is tracked in frontmatter and summarized in `THESIS_REGISTRY.md`.
- Generated evaluation artifacts live under `data/backtests/`, not in this folder.
- Code-generated thesis decisions are stored in `data/backtests/thesis_decisions.jsonl`.
- Live trading remains disabled until thesis promotion criteria are satisfied and reviewed manually.

These thesis files describe research intent. They are not live trading rules, execution instructions, or profitability claims.
