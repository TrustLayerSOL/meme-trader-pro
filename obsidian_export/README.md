# MemeTraderPro Obsidian Export

This package exports MemeTraderPro research state into an Obsidian vault as generated Markdown notes with YAML frontmatter.

Obsidian is not the source of truth. The source of truth remains the MemeTraderPro data layer:

- `data/wallet_quant_report.json`
- `data/wallet_outcome_ledger.json`
- `data/wallet_performance.json`
- `data/signal_contexts/contexts.jsonl`
- `data/rejected_signals/rejections.jsonl`
- `data/paper_trades.json`
- `data/postmortems/paper_closed.jsonl`
- `data/candidate_wallets.json`
- `data/wallet_candidate_audit.json`
- `data/replay_visibility_report.json`

## Setup

Set the vault path in your local environment:

```bash
OBSIDIAN_VAULT_PATH=/path/to/QuantResearchVault
```

Then run:

```bash
python3 -m obsidian_export.exporter
```

You can also pass the vault path manually:

```bash
python3 -m obsidian_export.exporter --vault /path/to/QuantResearchVault
```

For a small smoke test:

```bash
python3 -m obsidian_export.exporter --vault /tmp/QuantResearchVault --max-wallets 10
```

## Output

The exporter writes generated notes under:

```text
MemeTraderPro/
  Wallets/
  WalletCandidateReviews/
  Signals/
  RejectedSignals/
  PaperTrades/
  Postmortems/
  DailyReports/
  Dashboards/
```

Every generated note includes:

```text
GENERATED BY MEMETRADERPRO - DO NOT EDIT BELOW THIS LINE
```

Manual notes above that marker are preserved on future exports. Generated content below the marker is replaced from current MemeTraderPro data.

## Limits

Optional environment limits:

```bash
OBSIDIAN_EXPORT_MAX_WALLETS=100
OBSIDIAN_EXPORT_MAX_SIGNALS=500
OBSIDIAN_EXPORT_MAX_REJECTED_SIGNALS=500
OBSIDIAN_EXPORT_MAX_PAPER_TRADES=500
OBSIDIAN_EXPORT_MAX_POSTMORTEMS=500
```

Use `OBSIDIAN_EXPORT_MAX_WALLETS=all` or leave it unset to export all wallet notes.
