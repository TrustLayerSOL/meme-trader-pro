# Meme Trader Pro

Meme Trader Pro is a Solana meme-token research and trading assistant. It combines wallet tracking, token scoring, rug-risk checks, execution safety controls, paper trading, and operator dashboards for evaluating fast-moving Solana token opportunities.

## What it does

- Tracks selected Solana wallets and token activity
- Scores early token momentum, buyer behavior, liquidity, and execution risk
- Flags rug-risk and token-mechanics concerns before action
- Supports paper-trading workflows and post-trade review
- Provides dashboard and reporting utilities for operator decisions

## Safety

This project is intended for research, monitoring, and controlled operator workflows. Crypto trading is high risk. Review configuration carefully, keep API keys and wallet material in local environment variables only, and test changes before using any live execution path.
